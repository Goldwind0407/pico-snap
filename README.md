# 快趣拍

（舊名 PICO SNAP，程式碼和識別碼還沿用這個名字。）

可愛的韓系拍貼 App，用 Flutter 製作：像實體拍貼機一樣倒數連拍的四格拍貼、拍立得相機與拼貼、貼紙裝飾，加上去背、底片質感濾鏡、拍貼動態影片和製作過程縮時影片。所有資料都存在手機裡，不需要登入。

整體是粉嫩的照片日記風格：奶油色紙張、咖啡色細描邊、紙膠帶和手寫字。

## 功能

### 首頁

- 最上面是「快趣拍」標題，下面是拼貼風格的主視覺卡片和「開始製作」按鈕
- 「開始製作」和底部中間的相機按鈕都打開同一個「選一種玩法」選單（四種玩法，各有一行說明）
- 「選一種玩法」四種入口，排成兩排：四格拍貼、拍立得、拍立得拼貼、貼紙裝飾（中文為主，英文小字）；字體放大時卡片跟著變高，插圖不會被擠小
- 有編輯到一半的作品時，出現「繼續編輯草稿」（每份有縮圖），點了回到編輯器，也可以刪掉草稿
- 「今日風格」橫向模板列表（每款都放範例照片），點了進四格拍貼機、選好那款模板；區塊標題都是中文，英文是旁邊的小字
- 底部導覽列：首頁、作品集、中間凸起的相機按鈕（選一種玩法）、日記、素材
  - 「首頁」、「作品集」、「日記」、「素材」都是分頁；在其他分頁按返回鍵會先回首頁

### 四格拍貼

跟實體拍貼機一樣的流程（`lib/booth_screen.dart`）：

1. **選模板**：上方是放大的模板，下方分類和縮圖；可以選每張倒數 3、5、10 秒。
2. **開始倒數**：預設用前鏡頭。取景框是放大到這一格的模板：相機畫面在照片格裡，模板的圖案（貓咪、草莓等）壓在上面和周圍，可以配合裝飾擺姿勢；已經拍好的格子也看得到。
3. **一張一張拍**：大大的倒數數字、閃光、拍好的照片停一下，下方小格依序填滿，接著自動拍下一張。前鏡頭拍出來跟取景框一樣是鏡像。
4. **拍完再挑濾鏡**：套在全部照片上。按「重拍」可以只挑其中一張重拍（其他的留著），也可以全部重拍；重拍倒數時按返回，回到原本的照片。
5. **完成！**：收進 App 的作品集（不用存到手機相簿），可以勾選「同時做拍攝影片」——每一格播放按下快門前的那幾秒（像拍貼機的動態照片），套同一個濾鏡，播兩遍，最後停在成品。每一格只做一次、第二遍直接重播，所以做影片的時間是以前的一半左右。
6. 完成頁可以直接「加貼紙裝飾」（帶著照片、模板、濾鏡進編輯器，開在貼紙），裝飾完在編輯器按完成；不用先收一張沒裝飾的。按了完成之後可以「加貼紙裝飾」、「存到相簿」（圖片和影片一起）或「再拍一組」。從完成頁直接去裝飾的話，拍攝影片不會一起留。

選模板頁右上角「從相簿選照片」會進原本的四格編輯器，自己放照片。

- **23 款模板**，分成精選、日常可愛、底片復古、黑白、生日派對、婚禮、畢業、節慶、Y2K 九類（分類列可以左右滑）；自己做的模板在最前面的「我的」分類。
  - **精選 8 款**：插畫模板，貓咪、草莓等裝飾會壓在照片邊緣，跟實體拍貼機印出來的一樣。
  - **主題 15 款**：依場合分類的簡約紙質風格。模板不會改照片顏色，想要黑白照片就選「黑白」濾鏡。
  - 全部都是 Gemini 生成的圖，文字是印好的，不能改。照片格的位置是從圖上量出來的（`ArtFrame`）。
  - 以前用程式畫的 12 款（純色、點點、貓掌等外框）不再列在模板裡，只留作「素材 → 自己設計模板」的起始樣式。
- **四格編輯器**（「從相簿選照片」或拍完「加貼紙裝飾」進來）工具：模板、貼紙、文字、畫筆、濾鏡。還沒放照片時，畫面下方有大大的「選照片」按鈕，可以一次選好幾張，依序填進空格；之後要換一批照片，按標題列的相簿圖示。

### 拍立得相機

首頁的「拍立得」或底部中間的相機按鈕打開。流程跟四格拍貼一樣：

1. **選底片**：上方是放大的底片，下方先選系列再選底片，按「開始拍照」。這時還不選濾鏡，拍完看著相片再選。
2. **拍照**：取景框是沒有濾鏡的原本畫面；只剩大大的取景框（形狀跟相片窗格一樣）、相機和快門，旁邊是「換底片」和「從相簿」；可切換前後鏡頭。手機有超廣角或長焦時，取景框下方會出現 0.5× / 1× / 長焦，切換的是實體鏡頭（iPhone 每顆鏡頭各自切換；Android 用主鏡頭縮到 1 以下帶到超廣角）。機身上的紅色快門也能按。
3. **出片、顯影**：按快門有閃光和震動，馬達轉一下後底片從出片口吐出來；拿到前面後從淡灰藍的空白慢慢顯影，約 20 秒，輕點可跳過。搖手機會加快顯影（這個彩蛋 App 裡不特別說明）。相片吐出來之後相機預覽會暫停。
4. **濾鏡、手寫或貼貼紙**：
   - 「濾鏡」：相片放大，下方是這張相片套上每個濾鏡的小圖，點一個就換上去，按「選好了」回來；按鈕會寫著選了哪個濾鏡。每張相片都從原圖開始。
   - 「手寫」：相片放大，用手指直接在相片上寫字、畫畫，6 種顏色（每種底片有自己的預設筆色）、細／粗、復原、全部清掉。
   - 「貼貼紙」：相片放大，下方換成貼紙本，點一張貼上去，可以拖曳、縮放、旋轉、翻轉、刪除。
5. **完成！**：相片收進 App 的作品集，接著拍下一張；不一定要存到手機相簿。想放進相簿再按「存到相簿」（存的是當下的樣子，作品集要按完成才收）。還沒按完成就離開會先問。返回鍵從拍照回到選底片。

- **底片**：分成五個系列，上方切換系列，下方是那個系列底片的小圖：
  - 基本：白底片、黑底片、底片框、微笑、星星
  - 三麗鷗：凱蒂貓、大眼蛙、大耳狗、布丁狗、美樂蒂酷洛米、酷企鵝（**只供測試**）
  - 寶可夢：寶可夢框、心金魂銀、火紅葉綠、紅寶藍寶、鑽石珍珠、黑2白2、XY、究極日月、劍盾（**只供測試**）
  - 中職：中信兄弟、統一獅、樂天桃猿、富邦悍將、味全龍、台鋼雄鷹（**只供測試**）
  - 動漫：Keroro、名偵探柯南、蠟筆小新（**只供測試**）

  全部 3:4、一樣大；照片格透明，底片蓋在照片上，角色和裝飾可以壓在照片邊緣。拼貼編輯器的底片列也照系列排。
- **機身顏色**（奶油、天藍、粉紅、薄荷、黑）在右上角的 ⚙ 設定裡換，不放在每次拍照的流程裡。
- 沒有相機或沒給權限時，可以「從相簿」選照片，一樣有出片和顯影。
- 拍立得相機不再直接做拼貼；拼貼改從首頁的「拍立得拼貼」進去。

### 拍立得拼貼

- 首頁的「拍立得拼貼」打開。一開始是空的，按「選照片（1～6 張）」選幾張就放幾張。全部放滿之後，右上角的「從相簿選照片」可以整組換掉（一樣選幾張就幾張）。
- 拍立得貼著紙膠帶，用的是跟相機同一種底片，下面可以寫手寫字（預設的字中英混搭）。
- 工具：
  - 模板（新的拼貼一打開就在這裡）：彩虹天空、奶油紙、校園走廊、粉彩紙、野花、窗邊、小鎮街道，每款配好背景圖、拍立得的張數和位置、底片、手寫字、裝飾和整頁質感，都是 9:16。點了就套用，照片留著；換模板時上一款的裝飾會換掉，自己貼的貼紙留著。「空白」回到原本的樣子。全部都可以再自由移動、復原。模板在 `lib/collage_templates.dart`，背景圖在 `assets/backdrops/`（使用者自己生成的圖，縮到 1080×1920 以內）。
  - 版面：張數 1～6；排法「隨意」（Z 字形斜放）、「整齊」（排成一格一格）、「疊放」（大張、交錯疊在一起）；比例 9:16、1:1、4:5、3:4。照片會依張數和比例排在頁面中間、盡量放大，9:16 也不會空一大塊。
  - 背景：12 種圖案（素面、方格紙、點點、格紋、條紋、筆記本、棋盤、愛心、星星、紙紋、漸層、照片）× 14 種顏色。圖案都用程式畫（`lib/widgets/backdrop.dart`），用選的顏色畫，所以每個圖案配每個顏色都可以。圖案後面是 7 張內建背景圖（跟模板同一組，選了是清楚的）。「照片」預設用第一張照片，也可以「從相簿選背景」另外挑一張；可以「模糊」（再蓋一層選的顏色）或「清楚」（原本的照片）。
  - 底片：每張可以選自己的底片。小圖直接是那張照片放進各種底片的樣子；點畫面上的拍立得換一張設定，「套用到全部」一次換全部。
  - 貼紙、文字（改手寫字時，紅框框在那張的字上）、畫筆、濾鏡。
- 拼貼的工具面板都是同一個高度（貼紙除外），換工具時作品不會上下跳。
- 拍立得可以自由擺放（`lib/widgets/print_item.dart`）：直接拖曳移動，兩指放大縮小、旋轉；點一下選取後，右下角把手縮放旋轉、左上角拿掉這張。移動時會吸附頁面中線和其他拍立得的中心（出現藍色對齊線），角度接近正的時候會自動轉正。「排法」決定起始位置，再選一次排法會全部排回去。
- 選取的拍立得下方有：換照片（空的就是放照片）、調整（在框裡拖曳、縮放照片，按「調好了」結束）、擺正、拿掉；按「收起」或點頁面空白處回到原本的工具。
- 濾鏡分頁上方可以切到「整頁質感」（`lib/widgets/page_texture.dart`）：底片顆粒、暖陽、漏光、復古褪色、灰塵刮痕、紙張，蓋在整頁上（照片、背景、貼紙都一起），可以調強度；顆粒的粗細跟著頁面大小，存出來的高解析度圖看起來跟螢幕上一樣。
- 按完成時還有空白的拍立得會先問：「去放照片」、「留著空白」或「拿掉空白的」（有照片的往前補，張數變少）。
- 張數設 4 卻選了更多張：拼貼是空的或已經放滿時，選幾張（最多 6）就變幾張；只放了一部分時，只能補空的那幾格。

### 貼紙裝飾

- 雙色格紋背景和對話泡泡。
- 照片可以去背，去好背的主體加上白邊，像真的貼紙。
- 工具：貼紙、底紋、文字、畫筆、去背。

### 畫筆（三種模式都可以）

- 直接在作品上手寫字、塗鴉，畫在照片和貼紙上面。
- **畫筆**：像奇異筆、麥克筆，筆畫粗細跟著手的快慢變化，起筆有一點積墨，寫得快會有乾刷的細紋，淺色筆有亮面；**螢光筆**：半透明的粗線；**白邊筆**：外面包一圈白邊，像手帳裡的貼紙字；**橡皮擦**：在線上抹過去，碰到的線整條擦掉。
- 10 種顏色、細中粗 3 種粗細；「全部清掉」一次清空。
- 復原、重做連畫筆一起（一筆、一次擦除各算一步）。
- 寫完的筆畫會合成一張圖，只有正在寫的那一筆即時重畫，寫再多字也不會越來越卡。
- 畫的過程也會錄進縮時影片。

### 調整照片（三種模式都可以）

- 點空格選照片；點已經有照片的格子，可以拖曳移動、兩指縮放，也可以換照片、置中或移除。
- 照片一定會填滿格子，不會拖出白邊。

### 貼紙

- **裝飾**：貼紙本「我的」後面一頁是紙膠帶（素色、條紋、格紋）、撕紙、便利貼、標籤紙，各 7 種顏色，用程式畫的（`lib/widgets/deco_sticker.dart`），可以一直貼、不會用完。
- **貼紙本**：下方是一本貼紙本，一頁一張貼紙紙（亮片、甜點、英文字、閃閃、日本風、吉伊卡哇、寶可夢、Keroro、中職、UNO、Life is Good），左右滑或點上方標籤換頁，貼紙紙可以上下滑。點一張貼紙，它會從紙上浮起來貼到作品上；紙上比較大的貼紙，貼上去也比較大。跟真的貼紙一樣，內建的貼紙在同一個作品裡只能用一次：貼上去之後紙上那格就空了，在作品上刪掉（或復原）會回到紙上，換下一個作品又是一整張新的。自己做的貼紙不會用完。最前面幾頁是自己的貼紙紙（一張紙一頁，黃色標籤）；左邊的放大鏡可以用貼紙或貼紙紙的名字搜尋自己的貼紙。
- 貼紙紙原本是生成的整張圖（灰色底紙、白色模切邊），用程式把每張貼紙切下來（`assets/sticker_sheets/`、`lib/sticker_book.dart`）。App 裡的整張紙是用 `tool/whiten_sticker_sheets.py` 重新排成的：暖白色底紙，每張貼紙放回原位、下面墊一點柔和的陰影，白邊才看得出來。新增一本：照同樣規格生一張 3:4 的貼紙紙，切好之後加進 `stickerBooks`，再跑一次這支程式（在專案根目錄執行；後面接貼紙本 id，例如 `python tool/whiten_sticker_sheets.py uno`，就只重排那幾本）。
- 四格拍貼的拍貼條很窄，貼紙放在靠邊的地方時，把手可能超出拍貼條、點不到，要先把貼紙拖回中間。
- 拖曳、兩指縮放和旋轉；右下角把手調整大小和角度，右上角左右翻轉，左上角（紅框）刪除。把手的觸控範圍是 44 點，比畫出來的圓大，不容易按不到。

### 濾鏡

只套在照片上，模板、底片、貼紙都不受影響。目前有：

| 濾鏡 | 來源 |
|---|---|
| 原圖 | |
| 韓系奶油 | 調色配方（`lib/filter_recipes.dart`）：暖白、微抬黑位、綠色和藍色降飽和 |
| 濃烈負片 | 直接套用原始 `fuji_classic_neg_raw.cube`，保留原本強烈的對比與色彩 |
| 拍立得暖金 | 暖金膚色、青綠暗部、壓低紙白亮部，搭配細顆粒、柔化與微暖光暈 |
| 拍立得冷閃 | 冷藍暗部、較深黑位、保留暖膚色，搭配細顆粒、暗角與輕光暈 |
| 日系街拍 | `.cube` LUT，加輕微顆粒、暗角、柔化、光暈 |
| 復古柔和 | 原始 Hald 色彩映射異常；重建低對比褪色暖調配方，加輕柔化，保留舊 id |
| 冷調、暖調、柔軟、深秋、冷暖對比、馬卡龍、賽博朋克、黑白 | 自己在修圖 App 調的 Hald 圖（`design/hald/`） |

調色引擎、底片效果和讀調色檔的功能都在，新濾鏡可以寫成調色配方（`lib/filters.dart` 的 `photoFilters`），或放調色檔進 `assets/luts/`。

- **四格拍貼機**：拍完四張再挑，一次套在全部照片上。
- **四格編輯器**：工具列的「濾鏡」，每張照片可以各自選，也能「套用到全部照片」。
- **拍立得相機**：拍完、顯影之後才選，看著自己的相片小圖挑。
- **做法跟 Lightroom 預設一樣**：一款濾鏡可以是一份調色配方（`lib/filters.dart`），由調色引擎（`lib/color_grade.dart`）算成 33³ 的 3D LUT 套到照片上（背景執行緒）：
  - 色溫、色調、曝光
  - **HSL**：只動特定顏色，例如橘色（膚色）降飽和、提亮讓皮膚通透，綠色往黃或往青偏，藍色往青偏；灰色不會被染色
  - **壓高光、補陰影**
  - 底片式 S 形對比、**曲線**（黑色點往上拉＝褪色、空氣感；可以分 RGB 通道做交叉沖洗）
  - **分離色調**：暗部、亮部各自帶一點顏色，例如青橙
  - 飽和度、自然飽和度
  - **底片質感**（調色之後再做，模仿底片相機 App）：
    - **柔化**：稍微抹掉手機照片過度銳利的數位感
    - **高光光暈（Halation）**：底片上亮處的光會往外暈出一圈橘紅色，路燈、招牌、白衣服旁邊最明顯
    - **動態顆粒**：依亮度決定顆粒多寡，中間調最明顯，純黑、純白幾乎沒有，比平均撒一層雜訊自然
  - 再疊上暗角、閃光、漏光、柔霧、日期水印
- 拍立得相機的取景框現在不套濾鏡。原本的 GPU 即時濾鏡（`lib/live_filter.dart`、`shaders/film.frag`）還留著但沒有用到：共用 3D LUT，和成品一樣先調色再柔化，並加上高光光暈和顆粒；即時柔化、光暈的採樣方式及顆粒雜訊仍是近似效果，並非逐像素相同。Android、iOS 共用同一支著色器。手機不支援 Impeller 自訂濾鏡時，退回最接近的顏色矩陣預覽。
- LUT 與備援預覽矩陣在背景準備；各濾鏡縮圖共用縮小後的像素資料，最多保留四份來源，照片調色最多同時執行兩份。柔化的暫存緩衝區在 RGB 通道間重用。
- 儲存前會等待照片及濾鏡載入完成。四格拍貼、拍立得與拼貼會暫時依輸出尺寸重新解碼原始照片、套用濾鏡，截圖後恢復預覽尺寸；原始照片本身解析度不足時仍無法增加細節。
- 不做 RAW：手機拍出來或相簿裡的 JPG 已經被處理過，Flutter 相機也拿不到 RAW，所以都是從 JPG 開始調。

### 濾鏡檔（LUT）

可以把現成的調色檔做成濾鏡，放進 `assets/luts/`、重新建置，就會出現在濾鏡列表裡（順序照 `lutLooks` 寫的順序，沒寫的排在最後；取景框即時預覽和存檔顏色一樣）。

- **`.cube`**：DaVinci、Premiere、Photoshop 等匯出的 3D LUT，任何尺寸都可以（會換算成 33³）。
- **Hald 圖（`.png`）**：把 `design/hald/hald_identity_8.png` 匯入任何修圖 App（Lightroom、Snapseed、醒圖…），套上想要的調色後原尺寸匯出 PNG，放進 `assets/luts/`。那張圖就記下了整個調色。
- 檔名就是濾鏡的 id；中文名字和要疊上的底片效果（顆粒、暗角、柔化、光暈）寫在 `lib/lut_files.dart` 的 `lutLooks`，沒寫的用檔案裡的 TITLE 或檔名、不加效果。LUT 只管顏色，底片感要靠這些效果。
- **試過的來源**（檔案都已刪掉，要用再放回來）：
  - [RawTherapee Film Simulation Collection](https://rawpedia.rawtherapee.com/)（Pat David、Pavlov Dmitry、Michael Ezra，**CC BY-SA 4.0**）：可以商用，但要在 App 裡標示出處，換算過的檔案也要維持 CC BY-SA。
  - [spectral_film_lut](https://github.com/JanLohse/spectral_film_lut)（MIT）：照底片官方資料模擬沖印、自己產生 LUT（輸入輸出 sRGB、曝光補償約 -0.7，拍立得 -1.0 到 -1.3）。
  - 濾鏡名字用我們自己的，不用 Kodak、Fuji、Polaroid 等商標。
- **相機廠的 Log LUT**（例如 Fujifilm 給 GFX ETERNA 55 的 `FLog2_to_*.cube`）是給 F-Log2 影片用的。直接套在手機照片上會變得高對比、高飽和，目前就這樣放了 `fuji_classic_neg_raw`（濃烈負片）**只供自己測試**：這是 Fujifilm 的檔案，上架前要拿掉。想要接近相機原本的樣子，可以用 `python design/flog2_bake.py <Fuji 的 .cube> assets/luts/<名字>.cube "<標題>" 1.0` 先把 sRGB 換成 F-Gamut／F-Log2 再接上它（最後的數字是曝光倍率）。
- **授權**：`assets/luts/` 裡的檔案會進 Git。網路上的免費 LUT 大多只能自己用來調色、**不能放進 App 散布或販售**（例如 RocketStock 的 35 Free LUTs 明文禁止；Shutterstock 的免費包沒附授權）；上架前確認每個檔案都能散布。別的 App 內建的濾鏡也不要用 Hald 圖複製過來。
- **調 Hald 圖時只能動顏色**（曲線、色溫、HSL、飽和度等）。顆粒、柔化、模糊、暗角、紋理這類跟位置有關的效果會把色卡打亂，套到照片上會變成雜色或完全錯的顏色；這些效果改寫在 `lutLooks` 裡。
- **Hald 圖用 JPEG 匯出時**：壓縮會讓每一格顏色帶一點雜訊，套在平滑的天空、膚色上可能出現色塊。放進 `assets/luts/` 前先把 64³ 的表輕微平滑、存成無損 PNG（目前的色卡都是這樣處理的）。

### 去背

一頁完成，右上角一直有「做出來」的小預覽，點一下放大。下方四個模式：

- **選主體**：手機內建 AI（iPhone 用 Vision，Android 用 ML Kit）把照片裡的人和東西一個個找出來，點一下選或不選，可以多選；長按只留按到的那一個。兩個人黏在一起時，在中間畫一條線就能切開。AI 不能用或找不到，自動改用手動去背（GrabCut），也可以自己選。已經去好背的透明 PNG 直接用它的輪廓。
- **擦掉／補回**：預設「貼齊邊緣」，畫一筆或點一下，沿著邊緣整塊擦掉或補回，只改那一筆附近（移植自 color_pic）。打開「細修」變成塗到哪就是哪的筆刷，可以調粗細。兩指放大、拖曳；按住看原圖；可以換深色背景看清楚白色毛邊。
- **外框**：沿著輪廓，或做成方形、圓形、星形、愛心貼紙（拖曳、兩指縮放照片調整位置）；白邊無、細、粗。
- **材質**：霧面（原本的樣子）、亮片（細細的閃粉）、雷射（彩虹光澤）、寶石（像凸起的果凍，上面一道光澤）。都在手機上算，不用網路；只改照片的質感，白邊維持白色（`StickerFinish`、`applyFinish`）。
- 上方有復原、重做；第一次進來會跳出「去背小技巧」（3 條：選主體、擦掉補回、外框），之後按「？」再看；有自己修過還沒完成就離開會先確認（打開時自動找出來的主體不算）。AI 認不出來、已經自動改用手動去背時，就不再顯示「改用手動去背」的按鈕。
- 在 560 像素的小圖上去背（貼齊邊緣一筆約一兩秒），做成貼紙時再把遮罩放大回 1024 像素套用。

去背用在兩個地方：貼紙裝飾模式（把作品的主照片去背），以及「我的素材」（把照片做成自己的貼紙）。

### 作品集

- 首頁底部的「作品集」分頁。四格拍貼、拼貼、貼紙、拍立得相機按「完成」就收進這裡（不一定要存到手機相簿），新的在前面：列表用最長邊 1400 像素的預覽，另外保留存檔時的原尺寸圖。
- 有兩種以上的作品時，可以按種類篩選。
- 點作品全螢幕看：左右滑換一件、兩指放大。下方按鈕：
  - **分享**：用手機的分享選單傳到 IG、LINE 等（原尺寸）。
  - **再編輯**：回到編輯器接著改，存檔會變成一件新作品，原本那件留著。編輯器做的作品和四格拍貼機拍的照片會留一份可編輯的內容（`works/<id>_piece/`，格式跟草稿一樣）；拍立得相機的相片沒有。
  - **看影片**：有一起存拍攝影片或縮時影片的作品，App 裡也留一份（`works/<id>.mp4`），可以重播和分享。
  - **存到相簿**：原尺寸，相簿裡的刪掉了也找得回來。比較早的作品沒有留原圖，按鈕會寫「存預覽版」。
  - **刪除**：只從作品集拿掉，相簿裡的不受影響。
- 只收圖片，影片只存在手機相簿。

### 日記

- 首頁底部的「日記」分頁。月曆上每天顯示那天第一件作品的縮圖，可以切換月份、「回到今天」。
- 點一天看那天的作品，也可以寫一句當天的心情（最多 60 字，手寫字型）；寫了日記的日子有小愛心。
- 作品和日記都存在手機裡（App 的文件資料夾 `works/`），關掉 App 再打開還在。

### 素材

首頁底部的「素材」分頁（頁面標題是「我的素材」）。自己的貼紙和模板都在這裡新增、修改、刪除；編輯作品時只能使用。還沒有貼紙或模板時，分頁裡是一張小插圖卡片，說明可以做什麼，按「做第一張貼紙」／「做第一個模板」直接開始。

- **貼紙**：照片去背做成貼紙（可以是輪廓或外框形狀、選材質），做好時可以取名字。
  - **貼紙紙**：自己的貼紙排在一張張白色貼紙紙上（每張下面有淡淡的陰影），每張紙有名字，例如「旅行」、「我家貓咪」；還沒放進紙的貼紙在「未分類」。每張紙就是貼紙本裡的一頁。
  - **一次選很多張**：長按一張貼紙開始選，之後點一下就加選；可以一起移到某張貼紙紙（或新的一張）、刪除，選一張時可以改名字。
  - **搜尋**：上方搜尋欄找貼紙或貼紙紙的名字。
  - 紙右邊的「⋯」：在這張紙上做新貼紙、改名字、刪除紙（上面的貼紙回到未分類）。
  - 存在 App 文件資料夾 `my_library/sheets.json`（紙和名字）和 `stickers/`（每張貼紙一個 PNG）。
- **模板**：自己設計四格模板。上方是放大的即時預覽，下方分頁一次只顯示一組選項：範本（從內建樣式開始改）、顏色（單色或上下漸層）、圖案（點點、貓掌、碎紙花、條紋、格紋、愛心、星星、小花、棋盤格、波浪；碎紙花用自己的彩色，其他用外框顏色調淡或調深。四條邊一律乾淨：圖案停在邊線內約 3.5 像素，愛心、星星這類小圖案只畫完整的，排列對齊左右邊框、照片之間的縫和上下空白；模板上的貼紙、紙膠帶超出邊緣的部分會裁掉，外框線畫在最上層）、照片格（方形、圓角、雲朵、愛心、星星；雲朵、愛心、星星會拉寬撐滿整格；以前存成波浪邊的變成雲朵；「哪一格」選全部一次套用，或選 1～4 格、直接點預覽上的格子，每格不同）、文字、貼紙。貼紙直接在預覽上拖曳、縮放、旋轉、翻轉，數量不限。點模板直接用它拍四格，按 ✎ 修改。
- 存在手機裡（App 的文件資料夾），關掉 App 再打開還在；刪除前會先確認。

### 儲存與影片

- **拍貼機的動態影片**：倒數時從取景框錄下每一格按快門前的最後幾秒（每秒約 10 格，最多 3 秒）。存檔時把四格一起播放兩輪、套上挑好的濾鏡，最後停在成品，一樣是 9:16 MP4。偶爾抓到的空白畫面會自動跳過；某一格完全沒錄到就放那張照片。
- 右上角「完成」：作品收進作品集（高畫質 PNG，最長邊約 3000 像素），可以勾選同時做縮時影片、也存到手機相簿（預設不勾，勾過會記住；相簿是「快趣拍」，改名前存的在舊的「PICO SNAP」相簿）。存好之後會跳出「收進作品集了 ♡」：看得到成品，可以「存到相簿」（沒勾的話）、「看作品、分享」（直接打開作品集裡這件，返回回到首頁）、「繼續編輯」或「回首頁」。存檔時自動隱藏「放照片」提示、選取框和貼紙把手。
- **編輯器的縮時影片**：可以同時做「製作過程」影片，編輯時自動記錄放照片、去背、貼貼紙、拖曳、縮放、翻轉（畫面有變化才截圖，最多每秒 4 張）。
- 影片是 9:16（720×1280，適合 Reels、TikTok）的 MP4，最後停在完成的作品 2 秒。編輯得少每格多停一下（過程至少約 4 秒）；編輯很久會抽掉一半畫格。
- 用手機內建的編碼器做影片（Android 是 MediaCodec，iPhone 是 AVAssetWriter）。
- **草稿**：編輯時自動存草稿（停手約 0.7 秒後、App 切到背景時）。草稿先寫照片檔、最後才寫內容，存到一半當掉也能讀回上一份。下次從首頁「繼續編輯草稿」接著做。已經收進作品集的作品拿去裝飾，什麼都沒改就離開，不會留草稿。
- **標題列**：返回、玩法名稱（四格拍貼／拍立得拼貼／貼紙裝飾）、復原、重做、儲存；按鈕都在標題列，不會蓋到作品。
- **文字**：上方切換「作品上的字」（四格底部、每張拍立得、對話泡泡）和「文字貼紙」。文字貼紙可以拖曳、縮放，選字型（手寫、落雁體、圓體、描邊：白字加粗的彩色邊）和 9 種顏色；選中一張文字貼紙再點字型或顏色，就改那一張。「手寫」的英文是 Caveat、中文是辰宇落雁體；「落雁體」整句都用辰宇落雁體；圓體和描邊的中文用手機內建的字型。App 裡其他手寫字（模板底部的字、日記）的中文也是辰宇落雁體。以前存的文字貼紙（`text:` 開頭）照樣讀得到，是手寫、深色。
- **復原／重做**：照片、裁切位置、文字、模板、背景、貼紙、筆畫都算在內。
- 模板分類跟拍貼機一樣是可以左右滑的圓角按鈕。
- 選了貼紙工具，貼紙本會加高（四格旁邊稍微矮一點，免得窄條變得更細）。貼紙最大只能放大到控制鈕還在畫布裡，窄窄的四格上也點得到刪除、翻轉、縮放。
- 拼貼和貼紙裝飾還沒有照片時，畫布會往上讓出「選照片」按鈕的位置，按鈕不會蓋到照片格。
- 編輯到一半按返回會先確認（作品會留成草稿）。判斷「有沒有改過」是直接比對作品內容，換模板、比例、背景、底紋也算；改了又改回原樣就不算。
- 自己的素材、作品集、日記寫進手機時一次寫一個檔案，先寫暫存檔再換上去，存到一半當掉也不會留下壞掉的檔案；讀不了的檔案會改名成 `.bad` 留著，不會被下次存檔蓋掉。

### 上架前要處理

這些現在放在 App 裡只是為了自己測試，**沒有授權，不能上架**：

- `assets/luts/fuji_classic_neg_raw.cube`：濃烈負片恢復使用原始 Fujifilm LUT；只供自己測試，上架前需移除或換成有散布授權的素材。
- 貼紙本：「亮片」幾乎照抄 Pico Cam 的付費貼紙；「日本風」裡有哥吉拉；「吉伊卡哇」、「寶可夢」、「Keroro」是別人的角色；「中職」是球隊商標；「UNO」是 Mattel 的牌面設計；「Life is Good」是那個品牌的商標（`lib/sticker_book.dart`）。「甜點」和「英文字」可以直接上架；「閃閃」裡那朵彩虹笑臉花很像村上隆的花，上架前最好拿掉或重畫。
- `assets/samples/` 的佔位人物照片、很像 instax mini 7 的相機外型（見「素材來源」）。

## 素材來源

- 介面示意圖、手繪貼紙、拍貼機模板、拍立得相機和底片都是用 Gemini 生成的，提示詞放在 `design/prompts/`。
- Gemini 生成的原始圖（`design/mockups/`、`design/templates/`）只留在本機，不上傳；App 用的是處理過的版本，放在 `assets/`。
- `assets/samples/` 的人物照片是從 AI 示意圖裁切下來的，**只是佔位用**。正式發布前請換成有使用權的照片。
- `assets/instant/` 的相機圖上原本有「instax」標誌，已經擦掉換成 App 名稱；相機外型仍然很像真實的 instax mini 7，上架前可以考慮換成自己的造型。
- 實體拍貼機的參考照片（`design/拍貼機範本/`）有版權，只留在本機當設計參考，已加入 `.gitignore`。
- 字型：[Nunito](https://fonts.google.com/specimen/Nunito)、[Caveat](https://fonts.google.com/specimen/Caveat)、[辰宇落雁體 2.0 細體](https://github.com/Chenyu-otf/chenyuluoyan_thin)，都採用 SIL Open Font License 1.1，可以隨 App 散布。辰宇落雁體約 9.5 MB，原檔未修改：「辰宇落雁」是保留名稱，裁切字集之類的修改版不能用這個名字。授權文字在 `assets/fonts/ChenYuluoyan-OFL.txt`，App 啟動時也登記進授權清單（`LicenseRegistry`）。

## 開發

1. 安裝 [Flutter](https://docs.flutter.dev/get-started/install) 3.41。
2. `flutter pub get`
3. `flutter run`（Android 模擬器或手機）
4. 測試：`flutter test`；靜態檢查：`flutter analyze`
5. 效能：`flutter drive --profile --driver=test_driver/perf_driver.dart --target=integration_test/perf_test.dart`（要接手機或模擬器），每一步的畫面耗時印在記錄裡、也寫到 `build/perf.json`。
6. 推到 GitHub 後，GitHub Actions（`.github/workflows/ci.yml`）會自動跑一次靜態檢查和全部測試。

去背的手機內建 AI、相機、存相簿、影片編碼都要在手機或模擬器上才會動；在測試裡會自動改用備案（例如 GrabCut）或顯示錯誤訊息。

## App 圖示

- 原圖是 `design/app_icon.png`（Gemini 生成，粉紅背景上吐出四格小插圖的拍立得相機）。換圖：把新的正方形圖放到那裡，在專案根目錄跑 `python tool/make_app_icons.py`，iOS 和 Android 所有尺寸都會重做。

## 建置 iPhone 版

### 用 Mac 產生沒簽名的 IPA

```
git clone https://github.com/Goldwind0407/pico-snap.git
cd pico-snap
flutter pub get
flutter build ios --release --no-codesign
cd build/ios/iphoneos
rm -rf Payload && mkdir Payload
cp -R Runner.app Payload/
zip -qr ~/Desktop/pico_snap-unsigned.ipa Payload
```

之後更新只要 `git pull`，再從 `flutter build` 那一步開始。

### 沒有 Mac：Codemagic 雲端建置

設定寫在 `codemagic.yaml`：

1. 用 GitHub 帳號登入 Codemagic，加入 `pico-snap` 這個倉庫。
2. 選 **ios-unsigned** 工作流程，分支選 `main`，按 **Start new build**。只有手動按才會建置，可以節省免費額度。
3. 建好之後，在 Artifacts 下載 `pico_snap-unsigned.ipa`。

### 安裝到 iPhone

在 Windows 用 [Sideloadly](https://sideloadly.io) 以自己的 Apple ID 簽名安裝。

- 用免費 Apple ID 安裝的 App，7 天後要重新安裝一次。
- 第一次打開前，要先到 iPhone 的「設定 → 一般 → VPN 與裝置管理」信任自己的 Apple ID。

### iOS 設定重點

- 最低支援 iOS 15，只支援 iPhone，只能直式使用。
- **iPhone Duo（摺疊機）**：打開後的內螢幕不理會「只能直式」，App 會用接近正方形的大畫面顯示，所以版面是照寬度排的（寬度 700 以上算寬螢幕），不是照方向：
  - 編輯器：工具面板改到作品右邊（寬 400），每個工具拿到整個高度；窄的時候在下面。
  - 首頁：四種玩法排成一排。
  - 拍貼機、拍立得相機：按鈕和控制列最寬 560～600，置中。
  - 摺起來、打開時，畫面只是變大變小，編輯中的作品、拍到一半的相片都會留著（`test/ux_test.dart` 有測）。
  - 還沒用到摺痕位置、半摺角度：Flutter 在 iPhone 上拿不到（`MediaQuery.displayFeatures` 是空的）。要在 Mac 上用 Xcode 27.1 的 iPhone Duo 模擬器跑一次確認。
- `Info.plist` 寫好了相簿、相機、存到相簿的權限說明，以及麥克風說明（相機套件要求，拍照不錄音）。少了這些說明，iOS 會直接讓 App 閃退。
- Vision 去背和影片編碼寫在 `AppDelegate.swift`（不另開新檔，因為新的 .swift 檔要加進 Xcode 專案檔才會編譯）。iOS 17 以上可以分開切出每個主體；iOS 15、16 只能切人像。模擬器上 Vision 不能用，要用實機測。
- 已經採用 UIScene（`SceneDelegate.swift`）。iOS 27 起，沒有採用 UIScene 的 App 一打開就會被系統終止。

### Android 正式簽章

release 版要用自己的金鑰簽章才能上架。沒有設定時會用 debug 簽章（建置時會出現警告），只能自己裝來測。

1. 產生金鑰（只做一次，**金鑰和密碼弄丟就再也不能更新同一個 App**，要備份在安全的地方）：
   ```
   keytool -genkey -v -keystore ~/pico-snap-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. 建立 `android/key.properties`（已在 `.gitignore`，不會上傳）：
   ```
   storeFile=C:/Users/你/pico-snap-upload.jks
   storePassword=密碼
   keyAlias=upload
   keyPassword=密碼
   ```
3. `flutter build appbundle --release` 產生上架用的 AAB。

### Android 設定重點

- 去背用 Google Play 服務裡的 ML Kit 主體分割；沒有 Google Play 服務的手機會自動改用 GrabCut。
- 權限只有相機，以及舊版 Android（10 以下）存相簿需要的儲存權限；相機套件帶進來的錄音權限已經拿掉。
