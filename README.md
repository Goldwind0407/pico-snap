# PICO SNAP

A standalone, local-first Flutter photo booth, Polaroid, and cut-out app.

## Status

Prototype migration in progress. The initial UI includes four-cut, Polaroid, and cut-out modes. High-resolution export, local project persistence, and real background removal are not implemented yet.

## Run

Install Flutter, run `flutter create .` to generate platform folders, then `flutter pub get` and `flutter run`.
