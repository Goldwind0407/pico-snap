# PICO SNAP

可愛的韓系拍貼 App，用 Flutter 製作：像實體拍貼機一樣倒數連拍的四格拍貼、拍立得相機與拼貼、貼紙裝飾，加上去背、底片質感濾鏡、拍貼動態影片和製作過程縮時影片。所有資料都存在手機裡，不需要登入。

整體是粉嫩的照片日記風格：奶油色紙張、咖啡色細描邊、紙膠帶和手寫字。

## 功能

### 首頁

- 拼貼風格的主視覺卡片和「開始製作」按鈕（進四格拍貼機）
- 三種玩法入口：四格拍貼（Four Cuts）、拍立得（Polaroid）、貼紙裝飾（Sticker）
- 「今日風格」橫向模板列表，點了進四格拍貼機、選好那款模板
- 右上角的相簿圖示打開**作品集**
- 底部導覽列：首頁、日記、中間凸起的相機按鈕（打開拍立得相機）、商店、我的
  - 「首頁」、「日記」和「我的」是分頁；在其他分頁按返回鍵會先回首頁
  - 商店還沒做，按了會顯示「即將推出」

### 四格拍貼

跟實體拍貼機一樣的流程（`lib/booth_screen.dart`）：

1. **選模板**：上方是放大的模板，下方分類和縮圖；可以選每張倒數 3、5、10 秒。
2. **開始倒數**：預設用前鏡頭。取景框是放大到這一格的模板：相機畫面在照片格裡，模板的圖案（貓咪、草莓等）壓在上面和周圍，可以配合裝飾擺姿勢；已經拍好的格子也看得到。
3. **一張一張拍**：大大的倒數數字、閃光、拍好的照片停一下，下方小格依序填滿，接著自動拍下一張。前鏡頭拍出來跟取景框一樣是鏡像。
4. **拍完再挑濾鏡**：套在全部照片上；不滿意可以「全部重拍」。
5. **完成儲存**：存成 PNG，可以勾選「同時存拍攝影片」——每一格播放按下快門前的那幾秒（像拍貼機的動態照片），套同一個濾鏡，最後停在成品。
6. 存好之後可以「加貼紙裝飾」（帶著照片、模板、濾鏡進編輯器）或「再拍一組」。

選模板頁右上角「從相簿選照片」會進原本的四格編輯器，自己放照片。

- **20 款模板**，分成精選、可愛、經典、生日、應援五類；自己做的模板在最前面的「我的」分類。
  - **精選 8 款**：Gemini 生成的插畫模板，貓咪、草莓等裝飾會壓在照片邊緣，跟實體拍貼機印出來的一樣。文字是印好的，不能改。
  - **其他 12 款**：程式繪製，外框（純色、漸層、點點、貓掌、碎紙花、條紋）、照片格形狀（方形、圓角、雲朵、波浪邊）、底部樣式（手寫字、PICO SNAP 標誌加日期、大標題）、印好的貼紙，部分是黑白照片。底部文字可以改。
- **四格編輯器**（「從相簿選照片」或拍完「加貼紙裝飾」進來）工具：模板、貼紙、文字、畫筆、濾鏡。

### 拍立得相機

- 首頁的 Polaroid 或底部中間的相機按鈕打開。
- **取景**：上方大取景框（形狀跟相片窗格一樣，看到的就是會印出來的範圍），相機鏡頭裡也有即時畫面；可切換前後鏡頭。
- **焦段**：手機有超廣角或長焦鏡頭時，取景框下方會出現 0.5× / 1× / 長焦，切換的是實體鏡頭，不是數位放大（iPhone 每顆鏡頭各自切換；Android 用主鏡頭縮到 1 以下帶到超廣角）。只有一顆鏡頭就不顯示。
- **外觀**：5 種機身顏色（奶油、天藍、粉紅、薄荷、黑）、白底片或黑底片、13 款濾鏡（取景框即時顯示完整效果）。機身上的紅色快門也能按。
- **出片**：按快門有閃光和震動，馬達轉一下後底片從相機頂部的出片口穩定吐出，尾端卡在出片口。
- **顯影**：拿到前面後，從淡灰藍的空白慢慢顯影，約 20 秒，輕點可跳過。搖手機會加快顯影、相片會跟著晃（這個彩蛋 App 裡不特別說明）。
- **拍完**：在相片下方寫字、存到相簿、再拍一張；拍好的相片疊在左下角，按「做成拼貼」把最近 4 張（連底片、濾鏡、文字）放進拍立得拼貼。
- 沒有相機或沒給權限時，可以「從相簿」選照片，一樣有出片和顯影。

### 拍立得拼貼

- 4 張拍立得斜放成 Z 字形，貼著紙膠帶，用的是跟相機同一種底片，下面可以寫手寫字。
- 工具：版面（比例 9:16、1:1、4:5、3:4，背景色，白／黑底片）、貼紙、文字、畫筆、濾鏡。

### 貼紙裝飾

- 雙色格紋背景和對話泡泡。
- 照片可以去背，去好背的主體加上白邊，像真的貼紙。
- 工具：貼紙、底紋、文字、畫筆、去背。

### 畫筆（三種模式都可以）

- 直接在作品上手寫字、塗鴉，畫在照片和貼紙上面。
- **畫筆**：一般的線；**螢光筆**：半透明的粗線；**白邊筆**：外面包一圈白邊，像手帳裡的貼紙字；**橡皮擦**：在線上抹過去，碰到的線整條擦掉。
- 10 種顏色、細中粗 3 種粗細；「全部清掉」一次清空。
- 右下角的復原連畫筆一起復原（一筆、一次擦除各算一步）。
- 畫的過程也會錄進縮時影片。

### 調整照片（三種模式都可以）

- 點空格選照片；點已經有照片的格子，可以拖曳移動、兩指縮放，也可以換照片、置中或移除。
- 照片一定會填滿格子，不會拖出白邊。

### 貼紙

- 16 款手繪貼紙和一些 emoji，加上自己做的貼紙（「📷 我的」）。
- 拖曳、兩指縮放和旋轉；右下角把手調整大小和角度，右上角左右翻轉，左上角刪除。
- 左下角可以復原。

### 濾鏡

只套在照片上，模板、底片、貼紙都不受影響。13 款，參考熱門拍照 App 的質感濾鏡，名稱用自己的：

| 濾鏡 | 特色 |
|---|---|
| 日系富士 | 日系底片：天空偏青、綠葉偏薄荷、膚色乾淨 |
| 千禧 CCD | 2000 年代數位相機：直閃、高光泛光、偏冷紫、日期水印 |
| 青橙 | 陰影偏青、高光偏橙，電影感 |
| 黑茶 | 墨黑碳灰、幾乎無彩度，高冷感 |
| 暖底片 | 暖金色底片、褪色黑＋顆粒 |
| 冷淡灰 | 冷灰、低飽和、霧面 |
| 冷豔閃光 | 冷藍、高對比、閃光燈暗角 |
| 清透野餐 | 明亮乾淨、綠色清新 |
| 浪漫柔霧 | 粉紫柔霧 |
| 漏光老照片 | 拋棄式相機：高對比、紅橘漏光、日期水印 |
| 霧面電影 | 黑色不純黑的啞光復古 |
| 銀鹽黑白 | 拍貼機經典黑白底片：濃黑、銀灰高光、膚色偏亮 |
| 夜景電影 | 夜拍用：青色暗部、路燈與招牌周圍的橘紅光暈、粗顆粒 |

- **四格拍貼機**：拍完四張再挑，一次套在全部照片上。
- **四格編輯器、拍立得拼貼**：工具列的「濾鏡」，每張照片可以各自選，也能「套用到全部照片」。
- **拍立得相機**：拍照前選，拍出來的相片就是那個濾鏡。
- **做法跟 Lightroom 預設一樣**：每款濾鏡是一份調色配方（`lib/filters.dart`），由調色引擎（`lib/color_grade.dart`）算成 33³ 的 3D LUT 套到照片上（背景執行緒）：
  - 色溫、色調、曝光
  - **HSL**：只動特定顏色，例如橘色（膚色）降飽和、提亮讓皮膚通透，綠色往黃或往青偏，藍色往青偏；灰色不會被染色
  - **壓高光、補陰影**
  - 底片式 S 形對比、**曲線**（黑色點往上拉＝褪色、空氣感；可以分 RGB 通道做交叉沖洗）
  - **分離色調**：暗部、亮部各自帶一點顏色，例如青橙
  - 飽和度、自然飽和度
  - **底片質感**（調色之後再做，模仿底片相機 App）：
    - **柔化**：稍微抹掉手機照片過度銳利的數位感
    - **高光光暈（Halation）**：底片上亮處的光會往外暈出一圈橘紅色，路燈、招牌、白衣服旁邊最明顯
    - **動態顆粒**：依亮度決定顆粒多寡，中間調最明顯，純黑、純白幾乎沒有，比平均撒一層雜訊自然
  - 再疊上暗角、閃光、漏光、柔霧、日期水印
- 拍立得相機的取景框用 GPU 即時套濾鏡（`shaders/film.frag`）：同一份 3D LUT、柔化、高光光暈、動態顆粒，看到的就是拍出來的樣子；Android、iOS 共用同一支著色器，不用寫原生程式。手機不支援 Impeller 自訂濾鏡時，退回最接近的顏色矩陣預覽。
- 不做 RAW：手機拍出來或相簿裡的 JPG 已經被處理過，Flutter 相機也拿不到 RAW，所以都是從 JPG 開始調。

### 濾鏡檔（LUT）

可以把現成的調色檔做成濾鏡，放進 `assets/luts/`、重新建置，就會出現在濾鏡列表最後面（取景框即時預覽和存檔顏色一樣）。

- **`.cube`**：DaVinci、Premiere、Photoshop 等匯出的 3D LUT，任何尺寸都可以（會換算成 33³）。
- **Hald 圖（`.png`）**：把 `design/hald/hald_identity_8.png` 匯入任何修圖 App（Lightroom、Snapseed、醒圖…），套上想要的調色後原尺寸匯出 PNG，放進 `assets/luts/`。那張圖就記下了整個調色。
- 檔名就是濾鏡的 id；中文名字和要疊上的底片效果（顆粒、暗角、柔化、光暈）寫在 `lib/lut_files.dart` 的 `lutLooks`，沒寫的用檔案裡的 TITLE 或檔名、不加效果。LUT 只管顏色，底片感要靠這些效果。
- **底片濾鏡**：`film_*.cube` 是從 [RawTherapee Film Simulation Collection](https://rawpedia.rawtherapee.com/)（Pat David、Pavlov Dmitry、Michael Ezra，**CC BY-SA 4.0**）的 Hald 圖換算成 33³ 的。這個授權可以商用、放進 App，但**要在 App 裡標示出處**，換算過的檔案也要維持 CC BY-SA。濾鏡名字用我們自己的，不用 Kodak、Fuji、Polaroid 等商標。
- **底片沖印模擬**：`sfl_*.cube` 是用開源工具 [spectral_film_lut](https://github.com/JanLohse/spectral_film_lut)（MIT）照底片官方技術資料模擬「底片曝光 → 印到相紙」做出來的（輸入、輸出都是 sRGB，33³，曝光補償 -0.7，拍立得 -1.0 到 -1.3）。濾鏡是我們自己產生的，不是別人的調色檔。
- **授權**：`assets/luts/` 裡的檔案都進 Git（倉庫是私人的、App 還沒上架，Codemagic 建置 iPhone 版時才拿得到）。**上架前要拿掉授權不明的**：Shutterstock 那 13 款（`BlueHour.cube` 等沒有 `film_`、`sfl_` 開頭的）沒附授權檔；`film_*`、`sfl_*` 可以留。網路上的免費 LUT 大多只能自己用來調色、**不能放進 App 散布或販售**（例如 RocketStock 的 35 Free LUTs 明文禁止）；要上架的濾鏡只放自己調的，或買了可商用、可內嵌在 App 的授權。

### 去背

一頁完成，右上角一直有「做出來」的小預覽，點一下放大。下方四個模式：

- **選主體**：手機內建 AI（iPhone 用 Vision，Android 用 ML Kit）把照片裡的人和東西一個個找出來，點一下選或不選，可以多選；長按只留按到的那一個。兩個人黏在一起時，在中間畫一條線就能切開。AI 不能用或找不到，自動改用手動去背（GrabCut），也可以自己選。已經去好背的透明 PNG 直接用它的輪廓。
- **擦掉／補回**：預設「貼齊邊緣」，畫一筆或點一下，沿著邊緣整塊擦掉或補回，只改那一筆附近（移植自 color_pic）。打開「細修」變成塗到哪就是哪的筆刷，可以調粗細。兩指放大、拖曳；按住看原圖；可以換深色背景看清楚白色毛邊。
- **外框**：沿著輪廓，或做成方形、圓形、星形、愛心貼紙（拖曳、兩指縮放照片調整位置）；白邊無、細、粗。
- 上方有復原、重做；第一次進來會跳出「去背小技巧」，之後按「？」再看；還沒完成就離開會先確認。
- 在 560 像素的小圖上去背（貼齊邊緣一筆約一兩秒），做成貼紙時再把遮罩放大回 1024 像素套用。

去背用在兩個地方：貼紙裝飾模式（把作品的主照片去背），以及「我的素材」（把照片做成自己的貼紙）。

### 作品集

- 首頁右上角打開。每次存到相簿（四格拍貼、拼貼、貼紙、拍立得相機），App 會自動收一份在這裡（最長邊 1400 像素），新的在前面。
- 有兩種以上的作品時，可以按種類篩選。
- 點作品全螢幕看：左右滑換一件、兩指放大，可以「再存一次到相簿」（相簿裡的刪掉了也找得回來）或從作品集刪掉（相簿裡的不受影響）。
- 只收圖片，影片只存在手機相簿。

### 日記

- 首頁底部的「日記」分頁。月曆上每天顯示那天第一件作品的縮圖，可以切換月份、「回到今天」。
- 點一天看那天的作品，也可以寫一句當天的心情（最多 60 字，手寫字型）；寫了日記的日子有小愛心。
- 作品和日記都存在手機裡（App 的文件資料夾 `works/`），關掉 App 再打開還在。

### 我的素材

首頁底部的「我的」分頁。自己的貼紙和模板都在這裡新增、修改、刪除；編輯作品時只能使用。

- **貼紙**：照片去背做成貼紙（可以是輪廓或外框形狀）。編輯時在貼紙的「📷 我的」裡使用。
- **模板**：自己設計四格模板。上方是放大的即時預覽，下方分頁一次只顯示一組選項：範本（從內建樣式開始改）、顏色（單色或上下漸層）、圖案、照片格、文字、貼紙。貼紙直接在預覽上拖曳、縮放、旋轉、翻轉，數量不限。點模板直接用它拍四格，按 ✎ 修改。
- 存在手機裡（App 的文件資料夾），關掉 App 再打開還在；刪除前會先確認。

### 儲存與影片

- **拍貼機的動態影片**：倒數時從取景框錄下每一格按快門前的最後幾秒（每秒約 10 格，最多 3 秒）。存檔時把四格一起播放兩輪、套上挑好的濾鏡，最後停在成品，一樣是 9:16 MP4。偶爾抓到的空白畫面會自動跳過；某一格完全沒錄到就放那張照片。
- 按「儲存」輸出高畫質 PNG（最長邊約 3000 像素），存到手機相簿的「PICO SNAP」相簿。存檔時自動隱藏「tap to add」、選取框和貼紙把手。還沒放照片時不能存。
- **編輯器的縮時影片**：可以同時存「製作過程」影片，編輯時自動記錄放照片、去背、貼貼紙、拖曳、縮放、翻轉（畫面有變化才截圖，最多每秒 4 張）。
- 影片是 9:16（720×1280，適合 Reels、TikTok）的 MP4，最後停在完成的作品 2 秒。編輯得少每格多停一下（過程至少約 4 秒）；編輯很久會抽掉一半畫格。
- 用手機內建的編碼器做影片（Android 是 MediaCodec，iPhone 是 AVAssetWriter）。
- 編輯到一半按返回，會先問要不要離開；存過檔或沒改東西就直接離開。

## 專案結構

| 路徑 | 內容 |
|---|---|
| `lib/main.dart` | App 進入點與主題 |
| `lib/theme.dart` | 配色、手寫字型、提示訊息、確認對話框 |
| `lib/models.dart` | 模板、貼紙、格紋、自己的模板等資料 |
| `lib/filters.dart` | 濾鏡配方與底片效果 |
| `lib/live_filter.dart`、`shaders/film.frag` | 取景框的 GPU 即時濾鏡 |
| `lib/lut_files.dart` | 讀 `.cube` 和 Hald 圖做成濾鏡 |
| `lib/color_grade.dart` | 調色引擎：曲線、HSL、陰影高光、分離色調、3D LUT |
| `lib/home_screen.dart` | 首頁與底部導覽 |
| `lib/booth_screen.dart` | 四格拍貼機：選模板、倒數連拍、挑濾鏡、存圖和動態影片 |

## 素材來源

- 介面示意圖、手繪貼紙、精選模板、拍立得相機和底片都是用 Gemini 生成的，提示詞放在 `design/prompts/`。
- Gemini 生成的原始圖（`design/mockups/`、`design/templates/`）只留在本機，不上傳；App 用的是處理過的版本，放在 `assets/`。
- `assets/samples/` 的人物照片是從 AI 示意圖裁切下來的，**只是佔位用**。正式發布前請換成有使用權的照片。
- `assets/instant/` 的相機圖上原本有「instax」標誌，已經擦掉換成 PICO SNAP；相機外型仍然很像真實的 instax mini 7，上架前可以考慮換成自己的造型。
- 實體拍貼機的參考照片（`design/拍貼機範本/`）有版權，只留在本機當設計參考，已加入 `.gitignore`。
- 字型：[Nunito](https://fonts.google.com/specimen/Nunito)、[Caveat](https://fonts.google.com/specimen/Caveat)，兩者都採用 SIL Open Font License。

## 開發

1. 安裝 [Flutter](https://docs.flutter.dev/get-started/install) 3.41。
2. `flutter pub get`
3. `flutter run`（Android 模擬器或手機）
4. 測試：`flutter test`；靜態檢查：`flutter analyze`
5. 推到 GitHub 後，GitHub Actions（`.github/workflows/ci.yml`）會自動跑一次靜態檢查和全部測試。

去背的手機內建 AI、相機、存相簿、影片編碼都要在手機或模擬器上才會動；在測試裡會自動改用備案（例如 GrabCut）或顯示錯誤訊息。

## App 識別碼

iPhone 和 Android 都是 `com.goldwind.picosnap`。上架之後就不能再改。

## 建置 iPhone 版

### 用 Mac 產生沒簽名的 IPA

```
git clone https://github.com/Goldwind0407/pico-snap.git
cd pico-snap
flutter pub get
flutter build ios --release --no-codesign
cd build/ios/iphoneos
rm -rf Payload && mkdir Payload
cp -R Runner.app Payload/
zip -qr ~/Desktop/pico_snap-unsigned.ipa Payload
```

之後更新只要 `git pull`，再從 `flutter build` 那一步開始。

### 沒有 Mac：Codemagic 雲端建置

設定寫在 `codemagic.yaml`：

1. 用 GitHub 帳號登入 Codemagic，加入 `pico-snap` 這個倉庫。
2. 選 **ios-unsigned** 工作流程，分支選 `main`，按 **Start new build**。只有手動按才會建置，可以節省免費額度。
3. 建好之後，在 Artifacts 下載 `pico_snap-unsigned.ipa`。

### 安裝到 iPhone

在 Windows 用 [Sideloadly](https://sideloadly.io) 以自己的 Apple ID 簽名安裝。

- 用免費 Apple ID 安裝的 App，7 天後要重新安裝一次。
- 第一次打開前，要先到 iPhone 的「設定 → 一般 → VPN 與裝置管理」信任自己的 Apple ID。

### iOS 設定重點

- 最低支援 iOS 15，只支援 iPhone，只能直式使用。
- `Info.plist` 寫好了相簿、相機、存到相簿的權限說明，以及麥克風說明（相機套件要求，拍照不錄音）。少了這些說明，iOS 會直接讓 App 閃退。
- Vision 去背和影片編碼寫在 `AppDelegate.swift`（不另開新檔，因為新的 .swift 檔要加進 Xcode 專案檔才會編譯）。iOS 17 以上可以分開切出每個主體；iOS 15、16 只能切人像。模擬器上 Vision 不能用，要用實機測。
- 已經採用 UIScene（`SceneDelegate.swift`）。iOS 27 起，沒有採用 UIScene 的 App 一打開就會被系統終止。

### Android 正式簽章

release 版要用自己的金鑰簽章才能上架。沒有設定時會用 debug 簽章（建置時會出現警告），只能自己裝來測。

1. 產生金鑰（只做一次，**金鑰和密碼弄丟就再也不能更新同一個 App**，要備份在安全的地方）：
   ```
   keytool -genkey -v -keystore ~/pico-snap-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. 建立 `android/key.properties`（已在 `.gitignore`，不會上傳）：
   ```
   storeFile=C:/Users/你/pico-snap-upload.jks
   storePassword=密碼
   keyAlias=upload
   keyPassword=密碼
   ```
3. `flutter build appbundle --release` 產生上架用的 AAB。

### Android 設定重點

- 去背用 Google Play 服務裡的 ML Kit 主體分割；沒有 Google Play 服務的手機會自動改用 GrabCut。
- 權限只有相機，以及舊版 Android（10 以下）存相簿需要的儲存權限；相機套件帶進來的錄音權限已經拿掉。
