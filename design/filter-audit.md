# 濾鏡檢查與調整

以專案內 `girl1.jpg`、`duo.jpg` 人像、三種膚色色票、草綠／天空／紅黃與 256 階灰階進行比較。
名稱符合度是視覺設計判斷，這組素材不能代表所有光源、膚色及風景照片。

| 名稱 | 判斷與處理 |
| --- | --- |
| 原圖 | 保持原色。 |
| 濃烈負片 | 原本將 F-Log2 轉換 LUT 直接套在一般照片，紅色過強且亮部失去層次。改用 sRGB 負片配方：深陰影、S 曲線、適度彩度、抑制橙紅過飽和、微量顆粒。保留舊 ID，草稿仍可讀取。 |
| 日系街拍 | 暖膚色、冷青背景、暗角與輕微顆粒，符合目前命名方向，保留。 |
| 冷調 | 中性灰與背景偏冷青，膚色仍偏暖，保留。 |
| 暖調 | 暖橙膚色與米色亮部，保留。 |
| 柔軟 | 原本已有低對比、淡色調，但沒有空間柔化；新增輕微柔化，保留原調色。 |
| 深秋 | 草綠轉棕、暖橙紅較突出，符合秋季配色，保留。 |
| 膠片 | 原本已有褪色黑位與低彩度，補上細顆粒、輕柔化與弱光暈。 |
| 青橙 | 背景偏青、膚色偏橙，保留。 |
| 韓系奶油（新增） | 抬黑位、柔和曲線、暖白、降低綠藍彩度、輕微柔化；不靠全局增加曝光來製造亮感。 |

新配方在 `lib/filter_recipes.dart`，共用既有 33³ LUT／三線性插值管線；CPU 成品與 GPU 預覽共用相同調色資料，模糊及顆粒效果仍各有近似實作。
例如奶油配方將中灰 `[128,128,128]` 轉為 `[148,146,143]`、白色轉為 `[251,248,243]`，以微暖白取代濃黃色罩染。

另修正 `.cube` 的 `DOMAIN_MIN/MAX`：應先對**輸入座標**正規化再查表，不能正規化輸出 RGB。
依據 [OpenColorIO 的 Iridas Cube 實作](https://github.com/AcademySoftwareFoundation/OpenColorIO/blob/main/src/OpenColorIO/fileformats/FileFormatIridasCube.cpp)。
自訂輸入範圍會烘焙為至少 33³ 的標準 0–1 LUT；範圍邊界受離散網格精度限制。

重現比較圖：

```sh
flutter test tool/filter_audit.dart --dart-define=AUDIT_LABEL=after
```

產物在 `build/filter_audit/after.png` 與 `after.json`，使用實際 CPU 濾鏡管線及暗角，附灰階與色票。
標籤以穩定 ID 顯示，避免測試環境缺少中文字體；JSON 包含中文名稱。
`before` 是修改前保存的比較圖，重新執行工具只會產生當下版本的結果。
